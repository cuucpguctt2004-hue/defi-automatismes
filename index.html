Identités remarquables

  • (a + b)2 = a2 + 2ab + b2
  • (a − b)2 = a2 − 2ab + b2
  • (a + b)(a − b) = a2 − b2

Piège : (2x)2 = 2x × 2x = 4x2. Le nombre devant le x est aussi au carré !
